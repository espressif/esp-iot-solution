# ChangeLog

## v0.3.1 (2026-10-21)

### Bug Fixes

* Fix USB Bluetooth descriptors and ACL buffer sizing for Windows compatibility.

## v0.3.0 (2026-07-31)

### Enhancements

* Add ESP32-S31 support, including USB High-Speed operation on TinyUSB RHPort0.
* Add ESP-IDF 6.x compatibility and update the `espressif/tinyusb` dependency to `^0.19.0~3`.
* Allow applications to provide the GPIO mapping for an external USB PHY.

## v0.2.0 (2026-01-06)

* Add ESP32-P4 and USB High-Speed support.

## v0.1.0 (2024-05-23)

* Initial version.
