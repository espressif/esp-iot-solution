S3 RGB、S31 RGB、P4 MIPI DSI · 0° / 90° / 180° / 270° · present 与 adapter。顶部 Tab 切换板卡，内存按模式查看，诊断与逐场景分数按需展开。

数据口径与检测边界干净驱动成绩 / 独立诊断

正式帧率和内存取干净 IDF 轮，交接检测取独立轻量诊断轮，不混用成绩。每项完整 16 场景并成功关闭；仅 XIP ON，排除 NONE，adapter 不支持的 AUTO 记“−”。

内存默认展示四个剩余值，可切换“堆已用”（堆容量−剩余，运行期取局部峰值）。剩余越多越好，已用与静态占用越少越好；箭头始终显示 present−adapter，颜色按当前指标判断。ELF 静态段与堆分开列出，dummy 别名不重复计算，RTC / P4 SPM 不计入普通 SRAM 段。内部 RAM 与 PSRAM 的最低点不一定同时发生。

S3 使用实际 bounce 源；S31 使用 AXI 预取描述符所属 FB；P4 使用实际装载 DMA 帧的独立快照。后两者不等于逐像素扫描证据。地址命中按检查点累计，同次提前交接可产生多条记录，不等于多次独立撕裂；零命中只描述已覆盖检查点。unknown 单列，不算正常。

adapter 的 0° 双缓冲 FULL/DIRECT 检查独立确认等待；旋转及其他模式检查 pipeline 交还，不适用项明确标出。诊断窗口不含 open/close，丢弃入口首半帧，但包含结束统计日志。S3 供数不足/既有扫描重启与其他板硬件 underrun 分别计数；扫描重启不是芯片复位。只检测、记录，没有修复、assert 或故障注入。

绿色：present 指标更优（帧率、剩余越高越好；已用、静态占用越低越好）。箭头方向仅表示数值差值正负。供数不足、地址交接命中和 unknown 独立解释，详见各板诊断及原始证据。
