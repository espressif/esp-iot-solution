地址观察详见diagnostic-summary.json和网页诊断抽屉。RGB供数不足/扫描重启与地址交接命中分开记录；扫描重启不是MCU复位。MIPI未采集RGB专用供数计数，零值不能解释为已证明不存在带宽不足。驱动提交计数中的首帧同地址提交也不能直接等价于消费者提前归还buffer。
