# Security Policy

## Reporting a Security Issue

We welcome responsible reports of suspected security issues. Please report them privately to [bugbounty@espressif.com](mailto:bugbounty@espressif.com), following the [Espressif Security Incident Response Process](https://www.espressif.com/en/node/9599). This channel also accepts reports outside the bounty program.

Please include the affected version or commit, a description of the potential impact, and steps to reproduce the issue or a proof of concept. Do not disclose sensitive vulnerability details in public issues; coordinate disclosure with the security team.

## Bug Bounty Program

ESP-IoT-Solution provides components, examples, and reference material for IoT development. **ESP-IoT-Solution is not currently included in the Espressif Bug Bounty Program.** Reports concerning this repository are not eligible for bounty payments under that program. We continue to welcome responsible security reports.

If an issue also affects another Espressif product or SDK, its eligibility is evaluated separately under the [Espressif Bug Bounty Program](https://www.espressif.com/en/node/9599) scope and rules.
